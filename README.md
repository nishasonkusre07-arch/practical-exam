# 🏋️ Fitness Tracker System 📊

## 🌟 About the Project

The **Fitness Tracker System** is a Python-based project designed to track and analyze daily fitness activities. It helps users record their exercise details, calculate calories burned, analyze workout duration, and generate fitness reports.

This project uses Python programming concepts, Object-Oriented Programming (OOP), NumPy, Pandas, Matplotlib, and Seaborn to manage fitness data and visualize activity performance.

## 🎯 Project Objectives

- 🏃 Record daily fitness activities.
- 🔥 Calculate total calories burned.
- ⏱️ Calculate average exercise duration.
- 📊 Analyze fitness activity data.
- 📅 Generate weekly fitness reports.
- 🔍 Filter records by activity type.
- 📈 Display fitness data through different charts.
- 💾 Store and manage fitness records using a CSV file.

## 🛠️ Technologies Used

- 🐍 **Python** – Core programming language.
- 🧮 **NumPy** – Numerical calculations and statistical analysis.
- 🐼 **Pandas** – Data management and data analysis.
- 📊 **Matplotlib** – Creating data visualizations.
- 🎨 **Seaborn** – Creating attractive statistical charts.
- 📁 **CSV** – Storing fitness activity records.

## ✨ Key Features

### 1. 📋 View Activities
View all recorded fitness activities, including dates, activity types, exercise duration, and calories burned.

### 2. ➕ Add New Activity
Add new fitness records by entering the date, activity type, duration in minutes, and calories burned.

### 3. 🔥 Total Calories
Calculate the total calories burned across all recorded activities.

### 4. ⏱️ Average Duration
Calculate the average duration of fitness activities.

### 5. 📊 Activity Frequency
Display how frequently each activity type appears in the dataset.

### 6. 🧮 NumPy Analysis
Perform numerical analysis to calculate average, maximum, minimum, and total calories burned, along with exercise duration statistics.

### 7. 📅 Weekly Report
Generate a weekly summary of exercise duration and calories burned.

### 8. 🔍 Filter Activity
Search and display records for a specific activity, such as Running, Yoga, Walking, or Cycling.

### 9. 💪 Fitness Report
Generate an overall fitness summary containing total activities, total duration, total calories, average calories, and the most common activity.

### 10. 📈 Data Visualization

The project provides four visualization options:

- 📊 **Bar Chart:** Displays total exercise duration for each activity type.
- 📉 **Line Chart:** Shows calories burned over time.
- 🥧 **Pie Chart:** Displays the percentage distribution of calories burned by activity.
- 🔥 **Heatmap:** Visualizes calories burned by activity and date.

- 📘 **README.md** – Project documentation.

## 📑 Dataset Details

The project uses a CSV dataset to store fitness activity information.

The dataset contains the following columns:

- 📅 **Datetime** – Date of the fitness activity.
- 🏃 **Activity Type** – Type of exercise performed.
- ⏱️ **Duration (Minutes)** – Total duration of the activity.
- 🔥 **Calories Burned** – Number of calories burned.

Supported activity types include Running, Walking, Cycling, Yoga, Gym, Swimming, HIIT, Strength Training, and Stretching.
